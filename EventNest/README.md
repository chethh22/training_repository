# EventNest – Community Event Hub

Angular 20 learning project covering components, routing, CanActivate, services, sessionStorage, ngOnInit, @Input and ngOnChanges.

## Run
1. Open this folder in VS Code.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:4200.

Choose Admin, Organizer or Participant on the demo login screen. This is a learning demo, not production authentication.
